# 정보화교육장 배치 스튜디오

김천시 새 정보화교육장 9 × 12m를 계획하는 정적 웹 앱입니다. 외부 CDN이나 계정 연결 없이 동작합니다.

공개 사이트: https://new-class-ten.vercel.app/

## 빠른 사용

1. 가구를 공간으로 끌어 놓거나 ‘추천 배치’로 시작합니다.
2. 책상을 선택한 뒤 ‘모니터 · 본체 세트’에서 왼쪽·오른쪽 세트를 켜고 끕니다. 남은 세트는 기존 위치를 유지합니다.
3. 위쪽 ‘간격 표시’를 누르면 벽·가구의 거리와 보라색 책상 행 간격이 나타납니다. ‘책상 앞뒤 · 행 간격만’을 선택하면 행 사이 거리와 정면 벽 기준 테이프 위치를 보기 쉽게 확인할 수 있습니다. 가구 하나를 선택하면 네 벽과 가까운 물건까지의 거리도 볼 수 있습니다.
4. 오른쪽 위 ‘물건 추가’에서 이름·기본 모양·가로·깊이·높이·개수를 입력합니다. 기준 수량 제한은 기본 해제되어 있습니다.
5. ‘화이트보드’ 분류에서 원하는 규격을 클릭하면 스크린 뒤에 붙습니다. 드래그 배치 후에도 선택 패널의 ‘스크린 뒤에 붙이기’로 맞출 수 있습니다.
6. 위쪽 ‘스크린 올리기 / 내리기’ 또는 스크린 선택 패널에서 동작시킵니다. 약 1.1초의 모션으로 뒤의 보드가 나타나며, 올림 상태도 배치에 저장됩니다.
7. ‘저장 / 불러오기’에서 JSON 파일을 다운로드하면 다른 PC에서도 작업을 이어갈 수 있습니다.

- 3D 투시 / 2D 평면, 실제 45cm 타일, 드래그 배치 및 회전
- 3열 가구 목록 또는 아래쪽 2행 목록, 기준 수량 제한 선택 (기본 해제)
- 물건 추가 버튼으로 이름·모양·가로·깊이·높이·개수 입력, 최대 300개 배치
- 모서리·중심 스냅, 다중 선택, 6방향 맞춤, 가로·세로 동일 간격
- 충돌·출입문 앞 공간 표시, 거리 측정, 위치 잠금
- 브라우저 자동 저장, 이름별 배치안, JSON 가져오기·내보내기
- 2400 × 1740 PNG 도면, 첨부 사진 14개 확인
- 스위치 미니랙(60×60×90cm), 미니냉장고(48×50×83cm): 추정 치수이며 개별 수정 가능
- 사진의 책상 구조를 반영한 중앙 본체 받침대, 서랍장 제거
- 책상별 왼쪽·오른쪽 모니터와 본체를 세트로 표시/제거. 남은 세트의 위치 유지
- 벽·가구 간격 표시, 선택 가구의 가장자리 기준 거리와 전체 배치 간격 확인
- WebGL 사용이 제한되면 같은 Three.js 장면과 카메라를 Canvas로 투영하는 CPU 렌더러 자동 적용

## 책상 앞뒤 간격 · 현장 테이프 기준

파란색 치수는 스크린을 바라보는 방향에서 같은 책상줄의 앞 책상 뒤끝 → 다음 책상 앞끝까지입니다. 왼쪽·가운데·오른쪽 줄 모두 각 책상 사이에 직접 표시합니다. 줄마다 간격이 다르면 개별 거리가 표시되며, 중간에 책상이 없으면 같은 줄의 다음 책상까지 측정합니다. 스크린 회전을 반영해 앞뒤 방향을 정하고, 회전된 책상은 표시선이 실제 책상 가장자리와 만나는 점 사이를 잽니다. 간격 표시는 2D·3D 및 PNG 도면에 적용됩니다. 벽 기준 위치표는 공간을 가리지 않도록 기본 접힌 상태이며 클릭해 펼칠 수 있습니다.

## 책상 행 간격 · 현장 테이프 기준

정면 벽(Z=0)에서 후면 방향으로 1행, 2행 순서로 번호를 붙입니다. 컴퓨터책상을 우선 계산하며, ‘기존 책상 전체’를 선택하면 일반책상과 미니책상도 포함합니다. 앞뒤 중심 위치가 18cm 이내인 책상을 한 행으로 묶습니다.

보라색 치수는 앞 행의 뒤쪽 가장자리에서 다음 행의 앞쪽 가장자리까지입니다. 회전·치수 변경을 반영한 실제 바닥 투영 범위를 사용합니다. 행별 표에는 정면 벽에서 각 행의 앞쪽 가장자리까지 누적 거리도 표시합니다. 행 안에서 앞끝이 어긋나면 누적 위치를 범위로 표시하고 간격은 행 전체를 지나는 최소 여유로 계산합니다. 겹치는 경우 ‘겹침’으로 표시합니다. 가구 이동 시 즉시 갱신하며, 간격을 켜고 PNG를 내보내면 행 간격과 테이프 기준 표가 도면에도 포함됩니다.

## 추가 아이템과 화이트보드

가구 목록은 총 50종입니다. 새로 추가한 38종은 소파 4종, 탁상·사이드 테이블 4종, 상담 테이블 6종, 의자·스툴 6종, 쓰레기통·수납·정수기·옷걸이 9종, 상담 파티션 1종, 화이트보드 7종, 탁상용 프린터 1종입니다. 분류별 검색, 오른쪽 3열 및 아래쪽 2행 목록에서 모두 클릭·드래그 배치할 수 있습니다. 상담 테이블은 컴퓨터책상과 별개의 가구이며 PC가 붙지 않습니다.

벽걸이 보드는 두문 자석 화이트보드 판매 규격 90×60, 120×90, 150×90, 180×90, 180×120, 240×120cm를 반영했습니다. 이동식은 현대오피스 판면 120×90cm를 참고했습니다. 각 아이템에서 제품 출처를 열 수 있습니다. 벽걸이 두께·설치 높이 및 이동식 받침대 치수는 추정값이며 변경 가능합니다. 그 외 새 가구는 특정 제품을 재현한 것이 아니라 크기 조절 가능한 배치 검토용 모델입니다.

- 두문 규격: https://www.dreamoffice.com/shop/goods_list.php?ps_ctid=01240200
- 현대오피스 이동식: https://hd2.co.kr/product/detail.html?product_no=35113

탁상용 프린터는 42×36×25cm의 추정 치수로 모델링했습니다. 책상을 선택한 뒤 목록의 프린터를 클릭하면 그 책상 위에 올라갑니다. 드래그로 책상 위에 놓으면 윗면 높이를 맞추며, 선택 패널의 ‘가까운 책상 위에 올리기’로도 높이를 맞출 수 있습니다. 책상이나 프린터 받침대가 없을 때 일반 클릭 추가는 바닥에 배치합니다. 치수·바닥 높이는 수정 가능하며 기존 배치와 같은 방식으로 저장됩니다.

스크린 케이스의 위치를 고정한 채 원단과 하단 바를 함께 올리고 내립니다. 동작 중 반대 버튼을 누르면 현재 위치에서 방향을 바꿉니다. 운영체제의 모션 줄이기 설정은 즉시 전환으로 반영하며, 실행 취소와 v2 JSON 이전 파일 호환성을 유지합니다. 가구의 높이까지 고려하는 겹침 검사도 올라간 스크린의 실제 높이 범위를 사용합니다.

## 좌표와 출처

X는 왼쪽 벽, Z는 정면 벽에서 가구 중심까지의 거리(m)입니다. 천장은 추정 2.7m입니다. 사용자 확인에 따라 출입문과 창문 2개는 후면 9m 벽에 있습니다. 맞은편 벽에는 전기 단자함, IDF, 싱크대를 모델링했습니다. 전기 단자함의 왼쪽 간격은 파일명의 53cm를 사용했습니다. 그 외 설비 위치와 크기는 사진 추정값이며 공간 설정에서 수정할 수 있습니다.

컴퓨터책상(18), 일반책상(2), 미니책상(1), 캐비닛(1), 140cm 파티션(2), 80cm 파티션(2), 스크린(1)의 치수·수량은 첨부 파일명 기준입니다. 파티션 두께, 의자, PC 세트 치수는 추정입니다. 책상 위 PC 미리보기는 배치 수량에 포함하지 않습니다.

## 구성

`dist/index.html`, `style.css`, `app.js`, `furniture.mjs`, `extra-furniture.mjs`, `extra-models.js`, `screen-model.mjs`, `wall-placement.mjs`, `tabletop-placement.mjs`, `geometry.mjs`, `desk-rows.mjs`, `software-renderer.js`와 사진 및 로컬 Three.js 배포본을 정적 호스팅합니다. 로그인·회원가입·인증 API를 사용하지 않습니다. 배치 데이터는 방문자의 브라우저에 저장하며 서버로 전송하지 않습니다. 서버 저장이나 기기 간 자동 동기화는 없습니다. JSON 파일로 옮길 수 있습니다. 기존 v2 배치 파일도 불러올 수 있습니다.

## GitHub · Vercel

원본 저장소: https://github.com/glamping516/new_class

Vercel 프로젝트 `new-class`를 이 저장소에 연결했습니다. Production Branch는 `main`이며 이후 푸시가 자동 배포됩니다. 프레임워크는 Other, Root Directory는 저장소 루트, Build Command는 `npm run build`, Output Directory는 `dist`입니다. 설정은 `vercel.json`에 포함되어 있습니다. 이 앱에 비밀키나 환경변수는 필요하지 않습니다. Production의 로그인 보호는 꺼져 있습니다.

개발 전 `npm run build`로 JavaScript, 사진 경로, 회전된 물체의 실제 간격 및 PC 세트 설정을 검증할 수 있습니다. `furniture.mjs`에서 가구 목록과 고정 모니터 위치를 관리합니다. 책상별 `monitors` 배열이 모니터·본체·키보드 세트의 표시 상태를 저장합니다. 미니랙과 냉장고는 기본 각 1개입니다. 추가 모델·화이트보드 부착·스크린 모션 회귀 검사를 포함한 자동 테스트는 23개입니다. 거리 표시는 바닥 투영 면의 가장자리 기준이며 임의 회전에도 사각형 다각형 간 최단거리를 계산합니다.

검증: 회전된 가구 충돌 판정, 경계 제한, 스냅, 정렬 및 간격 계산을 Node에서 확인했습니다. 실제 브라우저에서 클릭/드래그 추가, 드래그 이동, 다중 선택, 맞춤·동일 간격, 공간 설정, PC 표시, 18개 책상 예시, 2D/3D 전환, 패널 이동, 배치안 저장, PNG 다운로드를 확인했습니다. 테스트 브라우저는 GPU가 비활성화되어 CPU 호환 렌더링으로 검증했습니다.

Three.js 라이선스는 `dist/vendor/THREE-LICENSE.txt`를 참고하세요.
