# 정보화교육장 배치 스튜디오

김천시 새 정보화교육장 9 × 12m를 계획하는 정적 웹 앱입니다. 외부 CDN이나 계정 연결 없이 동작합니다.

공개 사이트: https://new-class-ten.vercel.app/

## 빠른 사용

1. 가구를 공간으로 끌어 놓거나 ‘추천 배치’로 시작합니다.
2. 책상을 선택한 뒤 ‘모니터 · 본체 세트’에서 왼쪽·오른쪽 세트를 켜고 끕니다. 남은 세트는 기존 위치를 유지합니다.
3. 위쪽 ‘간격 표시’를 누르면 바닥 면의 가장자리 기준 거리(cm)가 나타납니다. 가구 하나를 선택하면 네 벽과 가까운 물건까지의 거리를 볼 수 있습니다.
4. 오른쪽 위 ‘물건 추가’에서 이름·기본 모양·가로·깊이·높이·개수를 입력합니다. 기준 수량 제한은 기본 해제되어 있습니다.
5. ‘저장 / 불러오기’에서 JSON 파일을 다운로드하면 다른 PC에서도 작업을 이어갈 수 있습니다.

- 3D 투시 / 2D 평면, 실제 45cm 타일, 드래그 배치 및 회전
- 3열 가구 목록 또는 아래쪽 2행 목록, 기준 수량 제한 선택 (기본 해제)
- 물건 추가 버튼으로 이름·모양·가로·깊이·높이·개수 입력, 최대 300개 배치
- 모서리·중심 스냅, 다중 선택, 6방향 맞춤, 가로·세로 동일 간격
- 충돌·출입문 앞 공간 표시, 거리 측정, 위치 잠금
- 브라우저 자동 저장, 이름별 배치안, JSON 가져오기·내보내기
- 2400 × 1740 PNG 도면, 첨부 사진 14개 확인
- 스위치 미니랙(60×60×90cm), 미니냉장고(48×50×83cm): 추정 치수이며 개별 수정 가능
- 사진의 책상 구조를 반영한 중앙 본체 받침대, 서랍장 제거
- 책상별 왼쪽·오른쪽 모니터와 본체를 세트로 표시/제거. 남은 세트의 위치 유지
- 벽·가구 간격 표시, 선택 가구의 가장자리 기준 거리와 전체 배치 간격 확인
- WebGL 사용이 제한되면 같은 Three.js 장면과 카메라를 Canvas로 투영하는 CPU 렌더러 자동 적용

## 좌표와 출처

X는 왼쪽 벽, Z는 정면 벽에서 가구 중심까지의 거리(m)입니다. 천장은 추정 2.7m입니다. 사용자 확인에 따라 출입문과 창문 2개는 후면 9m 벽에 있습니다. 맞은편 벽에는 전기 단자함, IDF, 싱크대를 모델링했습니다. 전기 단자함의 왼쪽 간격은 파일명의 53cm를 사용했습니다. 그 외 설비 위치와 크기는 사진 추정값이며 공간 설정에서 수정할 수 있습니다.

컴퓨터책상(18), 일반책상(2), 미니책상(1), 캐비닛(1), 140cm 파티션(2), 80cm 파티션(2), 스크린(1)의 치수·수량은 첨부 파일명 기준입니다. 파티션 두께, 의자, PC 세트 치수는 추정입니다. 책상 위 PC 미리보기는 배치 수량에 포함하지 않습니다.

## 구성

`dist/index.html`, `style.css`, `app.js`, `furniture.mjs`, `geometry.mjs`, `software-renderer.js`와 사진 및 로컬 Three.js 배포본을 정적 호스팅합니다. 로그인·회원가입·인증 API를 사용하지 않습니다. 배치 데이터는 방문자의 브라우저에 저장하며 서버로 전송하지 않습니다. 서버 저장이나 기기 간 자동 동기화는 없습니다. JSON 파일로 옮길 수 있습니다. 기존 v2 배치 파일도 불러올 수 있습니다.

## GitHub · Vercel

원본 저장소: https://github.com/glamping516/new_class

Vercel 프로젝트 `new-class`를 이 저장소에 연결했습니다. Production Branch는 `main`이며 이후 푸시가 자동 배포됩니다. 프레임워크는 Other, Root Directory는 저장소 루트, Build Command는 `npm run build`, Output Directory는 `dist`입니다. 설정은 `vercel.json`에 포함되어 있습니다. 이 앱에 비밀키나 환경변수는 필요하지 않습니다. Production의 로그인 보호는 꺼져 있습니다.

개발 전 `npm run build`로 JavaScript, 사진 경로, 회전된 물체의 실제 간격 및 PC 세트 설정을 검증할 수 있습니다. `furniture.mjs`에서 가구 목록과 고정 모니터 위치를 관리합니다. 책상별 `monitors` 배열이 모니터·본체·키보드 세트의 표시 상태를 저장합니다. 미니랙과 냉장고는 기본 각 1개입니다. 거리 표시는 바닥 투영 면의 가장자리 기준이며 임의 회전에도 사각형 다각형 간 최단거리를 계산합니다.

검증: 회전된 가구 충돌 판정, 경계 제한, 스냅, 정렬 및 간격 계산을 Node에서 확인했습니다. 실제 브라우저에서 클릭/드래그 추가, 드래그 이동, 다중 선택, 맞춤·동일 간격, 공간 설정, PC 표시, 18개 책상 예시, 2D/3D 전환, 패널 이동, 배치안 저장, PNG 다운로드를 확인했습니다. 테스트 브라우저는 GPU가 비활성화되어 CPU 호환 렌더링으로 검증했습니다.

Three.js 라이선스는 `dist/vendor/THREE-LICENSE.txt`를 참고하세요.
